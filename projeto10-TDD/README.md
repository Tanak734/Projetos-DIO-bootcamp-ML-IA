# Agente de Geração de Testes Unitários

Este projeto implementa um agente de IA que gera automaticamente testes unitários para código Python usando a biblioteca pytest. O agente utiliza LangChain e Azure OpenAI para analisar o código e criar testes relevantes.

<br>

## Funcionalidades

- Gera testes unitários para funções Python
- Inclui testes para casos de sucesso e falha
- Usa a biblioteca pytest para os testes
- Interface de linha de comando fácil de usar

<br>

## Pré-requisitos

- Python 3.8+
- Conta no Azure OpenAI
- Chave de API do Azure OpenAI
